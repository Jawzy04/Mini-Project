Mini Project: Program Data Mahasiswa 
Program Java untuk mengelola data mahasiswa (nama, NIM, nilai) dengan konsep OOP dan control flow. 

Fitur: 
Tambah data mahasiswa (jumlah minimal 3, input lewat Scanner) 
Penentuan Lulus atau Tidak Lulus (nilai 60 ke atas lulus) 
Data tersimpan ke file data_mahasiswa.txt 
Tampilkan semua data yang tersimpan lewat menu 

Cara menjalankan: 
javac Main.java 
java Main
